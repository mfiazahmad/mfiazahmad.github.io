**CRM & EMR middleware** — Synchronising GoHighLevel with EMR platforms (Zenoti, MindBody, Aesthetic Pro, Boulevard). Two-way sync, conflict handling, and sync logs that make failures diagnosable instead of mysterious.

**Direct-response commerce** — Sticky.io, Konnektive, and CheckoutChamp connected to payment processors, ad APIs, and fulfilment. Declined-order reruns, subscription migration between MIDs without breaking billing cycles, percentage-based order scrubbing.

**AI-assisted workflows** — A marketing email generator on the Claude API with a prompt orchestration layer handling personalisation tokens, campaign variants, and tone control. An appointment-booking bot writing directly into the GoHighLevel calendar. Both in production against real traffic.
